# Gamification Logic

## Зачем нужна геймификация

Геймификация в LifeOS должна усиливать долгосрочную мотивацию и показывать накопительный прогресс. Она не должна подменять реальную продуктивность декоративными баллами. Главная задача - связать полезные действия с видимым ростом пользователя.

## XP

XP - базовая единица прогресса. Опыт начисляется за действия, которые двигают пользователя вперед:

- создание первой цели;
- выполнение задачи;
- выполнение привычки;
- достижение streak;
- завершение цели;
- применение AI-рекомендации;
- получение достижения.

Каждое начисление фиксируется в `xp_events`, чтобы прогресс был объяснимым и проверяемым.

Прокачка навыка остается частью общей модели продукта, но не является обязательным XP-событием Core MVP.

## Уровни

Уровень пользователя рассчитывается на основе суммарного XP. На старте можно использовать простую шкалу:

- Level 1: 0 XP.
- Level 2: 100 XP.
- Level 3: 250 XP.
- Level 4: 500 XP.
- Level 5: 900 XP.

В будущем шкалу можно заменить формулой, но первая версия должна быть понятной пользователю и простой для тестирования.

## Streak

Streak отражает регулярность выполнения привычки. Он увеличивается, если пользователь выполняет привычку в ожидаемый день, и сбрасывается или приостанавливается при пропуске в зависимости от правил привычки.

Для первой версии достаточно:

- считать streak по ежедневным привычкам;
- хранить `current_streak` и `best_streak`;
- начислять дополнительные XP за milestone streak.

## Достижения

Достижения фиксируют значимые события. Они должны быть конкретными, редкими и понятными.

Примеры достижений первой версии:

- "Первая цель" - первая цель создана.
- "Первое действие" - первая задача выполнена.
- "Семь дней подряд" - привычка выполнена 7 дней подряд.
- "100 XP" - пользователь получил первые 100 XP.
- "Первый навык" - первый навык прокачан.
- "AI применен" - первая AI-рекомендация применена.

## Прогресс по сферам жизни

Каждая цель, задача, привычка и навык может быть связана со сферой жизни. Прогресс сферы рассчитывается на основе:

- активных целей и их выполнения;
- выполненных задач;
- регулярности привычек;
- XP, полученного в этой сфере;
- прокачки связанных навыков.

В первой версии прогресс можно показывать как простую агрегированную оценку, без сложного scoring.

## Прокачка навыков

Навык имеет уровень и XP. XP навыка может начисляться:

- за выполнение задач, связанных с навыком;
- за выполнение привычек, связанных с навыком;
- за завершение цели, связанной с навыком;
- за ручное обновление прогресса;
- в будущем - за подтвержденные образовательные активности.

В Core MVP навыки не обязательны. Если модуль Skills откладывается, общий XP пользователя уже работает через задачи, привычки, цели и достижения.

## Связь задач, привычек, целей и XP

- Задача дает XP за завершение.
- Привычка дает XP за регулярное выполнение.
- Цель получает прогресс через связанные задачи и привычки.
- Завершенная цель дает дополнительный XP.
- Достижения могут давать дополнительную награду.

Важно: XP должен начисляться на backend-слое, чтобы пользователь не мог подменить игровой прогресс с клиента.

## Базовые события начисления XP

| Событие | XP |
| --- | ---: |
| Создание первой цели | 20 |
| Выполнение задачи | 10 |
| Выполнение привычки | 5 |
| Streak 7 дней | 30 |
| Завершение цели | 100 |
| Создание навыка | 10, после включения Skills |
| Повышение уровня навыка | 50, после включения Skills |
| Применение AI-рекомендации | 15 |
| Получение достижения | зависит от достижения |

Эти значения предварительные и должны уточняться после тестирования поведения пользователей.
