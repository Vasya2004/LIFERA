# Product Spec: LifeOS

## Идея проекта

LifeOS - персональная операционная система для управления жизнью. Приложение объединяет цели, задачи, привычки, навыки, здоровье, капитал и достижения в один понятный интерфейс. Пользователь видит не только список дел, но и связь ежедневных действий с долгосрочным развитием.

## Главная проблема пользователя

Пользователь хочет развиваться системно, но данные о его жизни разрознены: задачи находятся в одном приложении, привычки - в другом, финансы - в таблице, цели - в заметках, здоровье - в трекере. Из-за этого сложно понять:

- какие действия действительно важны;
- какие сферы жизни проседают;
- как маленькие действия влияют на большие цели;
- что делать дальше;
- почему мотивация падает.

## Целевая аудитория

- Студенты и молодые специалисты, которые хотят системно развиваться.
- Предприниматели и фрилансеры, которым важно управлять временем, капиталом и навыками.
- Люди, интересующиеся self-improvement, продуктивностью и quantified self.
- Пользователи, которым нужны персональные рекомендации, а не просто трекер задач.

## Ценностное предложение

LifeOS помогает пользователю видеть свою жизнь как систему: ставить цели, превращать их в действия, отслеживать прогресс, получать мотивацию через игровые механики и использовать AI Coach для выбора следующего шага.

## Основные разделы приложения

- Dashboard - центральный экран с обзором прогресса, задач, привычек, XP и AI-рекомендаций.
- Goals / Цели - долгосрочные и краткосрочные цели по сферам жизни.
- Tasks / Задачи - конкретные действия, связанные с целями или созданные отдельно.
- Habits / Привычки - регулярные действия, streak и история выполнения.
- Skills / Навыки - развитие компетенций, уровни и связь с целями.
- Health / Здоровье - базовые показатели, самочувствие, сон, активность.
- Capital / Капитал - учет финансовых записей, активов и прогресса капитала.
- Achievements / Достижения - игровые награды, уровни, XP и milestones.
- AI Coach - помощник для постановки целей, декомпозиции и анализа прогресса.
- Profile / Профиль - персональные данные, выбранные сферы развития.
- Settings / Настройки - приватность, уведомления, тема, интеграции.

## Первая рабочая версия продукта

Первая версия должна доказать базовую ценность LifeOS: пользователь регистрируется, проходит onboarding, выбирает сферы развития, создает цель, получает задачи и привычки, выполняет действия, получает XP и видит прогресс на dashboard.

Минимальный состав первой версии:

- Supabase Auth.
- Профиль пользователя.
- Onboarding с выбором сфер жизни.
- Goals, Tasks, Habits.
- Базовый Dashboard.
- XP-события и несколько достижений.
- AI Coach для помощи с формулировкой цели и декомпозицией.
- RLS для пользовательских данных.

## Граница Core MVP

Core MVP должен доказать главный цикл продукта: цель -> задачи и привычки -> выполнение -> XP и достижения -> обзор на Dashboard -> следующий шаг от AI Coach.

В Core MVP входят:

- регистрация и вход через email;
- профиль и завершение onboarding;
- пользовательские сферы жизни;
- цели;
- задачи;
- привычки и ежедневные отметки;
- XP, уровни и 5-6 базовых достижений;
- Dashboard с агрегированным прогрессом;
- AI Coach только для целей, задач, привычек и следующего шага.

В Core MVP не входят полноценные разделы Skills, Health и Capital. Они могут присутствовать в навигационной концепции и модели будущего продукта, но не должны блокировать первую рабочую версию.

## Что не входит в первую версию

- Полноценная финансовая аналитика.
- Полноценный модуль Capital.
- Полноценный модуль Health.
- Полноценный модуль Skills с отдельной системой прокачки.
- Медицинские рекомендации.
- Интеграции с Apple Health, банковскими API и календарями.
- Социальные функции и командные пространства.
- Маркетплейс шаблонов.
- Платные подписки и Stripe.
- Нативное iOS-приложение.
- Сложная AI-память и автономные AI-агенты.

## Логика геймификации

Геймификация нужна не как декоративная механика, а как способ показать пользователю накопительный прогресс. В Core MVP XP начисляется за создание цели, выполнение задач, отметки привычек, streak, завершение цели и применение AI-рекомендаций. Прокачка навыков переносится в следующий этап, чтобы не смешивать мотивационное ядро с отдельной системой skill progression. Уровни отражают общий прогресс, achievements фиксируют важные milestones, streak поддерживает регулярность.

## Логика AI-помощника

AI Coach помогает пользователю превращать неопределенные намерения в конкретные действия. В первой версии он:

- помогает сформулировать цель;
- предлагает декомпозицию цели на задачи;
- предлагает привычки под выбранную сферу жизни;
- анализирует ограниченный контекст прогресса по целям, задачам и привычкам;
- предлагает следующий практический шаг.

AI не должен получать лишние персональные данные. Все запросы к OpenAI API должны идти только через backend-слой.

## Связь проекта с ВКР и стартапом

Для ВКР LifeOS демонстрирует полный цикл проектирования и разработки современного веб-приложения: анализ проблемы, архитектура, база данных, безопасность, AI-интеграция, UX-сценарии и оценка результата.

Для стартапа LifeOS может развиваться в subscription-based SaaS: бесплатный базовый трекер, платные AI-функции, продвинутая аналитика, PWA, iOS-версия и интеграции.
