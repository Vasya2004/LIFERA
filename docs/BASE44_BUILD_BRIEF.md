# Lifera — Base44 Build Brief

## Цель
Создать рабочий MVP веб-платформы Lifera для ВКР и дальнейшего развития в коммерческий сервис.

## Основной сценарий
Пользователь заходит на лендинг, регистрируется, попадает в личный кабинет, управляет целями, задачами, привычками, получает XP, достижения и AI-рекомендации.

## Основные страницы
1. Landing Page
2. Login / Registration
3. Dashboard
4. Goals
5. Tasks
6. Habits
7. Progress
8. Achievements
9. AI Coach
10. Pricing
11. Profile / Settings

## Free-функции
- цели
- задачи
- привычки
- базовый прогресс
- базовые достижения

## Premium-функции
- AI Coach
- расширенная аналитика
- дополнительные шаблоны
- продвинутые рекомендации
- расширенные достижения

## Демо-монетизация
Реализовать страницу Pricing и демонстрационный сценарий перехода на Premium.
После нажатия на кнопку оплаты пользователь получает статус premium.
Архитектуру сделать так, чтобы позже можно было подключить реальную платёжную систему.

## Сущности данных
- UserProfile
- Goal
- Task
- Habit
- HabitLog
- Achievement
- XPTransaction
- AIRecommendation
- Subscription
- Plan
- Payment

## Требования
- приложение должно быть адаптивным
- данные пользователя должны быть изолированы
- premium-функции должны быть скрыты для free-пользователей
- интерфейс должен быть современным, premium, clean SaaS
- проект должен быть пригоден для демонстрации на защите ВКР
