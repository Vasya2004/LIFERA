# Diploma Notes

## Объект разработки

Объект разработки - веб-приложение Lifera для персонального управления целями, задачами, привычками, навыками, здоровьем, капиталом и личным прогрессом.

## Предмет разработки

Предмет разработки - архитектура, модель данных, пользовательские сценарии, AI-модуль и игровые механики персональной цифровой экосистемы управления развитием.

## Цель ВКР

Разработать веб-приложение для системного управления личными целями и прогрессом с использованием современных web-технологий, геймификации и AI-рекомендаций.

## Задачи ВКР

- Проанализировать проблему разрозненного управления личными целями и задачами.
- Сформировать требования к веб-приложению.
- Спроектировать архитектуру Lifera.
- Разработать модель данных и правила доступа.
- Реализовать основные пользовательские сценарии.
- Добавить геймификацию через XP, уровни и достижения.
- Интегрировать AI Coach через безопасный backend-слой.
- Провести тестирование ключевых сценариев.
- Оценить практическую значимость и перспективы развития.

## Инновационность проекта

Инновационность Lifera заключается в объединении нескольких подходов:

- персональная система управления жизнью;
- AI-помощник для постановки целей и выбора действий;
- геймификация реального прогресса;
- единая модель данных для целей, задач, привычек и навыков;
- mobile-first SaaS-архитектура с перспективой PWA и iOS.

## Как описать архитектуру

Архитектуру можно описать как full-stack web-приложение на Next.js:

- frontend на React и TypeScript;
- UI на Tailwind CSS и shadcn/ui;
- backend на Route Handlers и Server Actions;
- Supabase PostgreSQL как база данных;
- Supabase Auth и RLS как слой безопасности;
- OpenAI API через backend;
- Vercel как платформа деплоя.

Важно подчеркнуть разделение ответственности: frontend отображает интерфейс, backend проверяет доступ и выполняет бизнес-логику, база данных защищает пользовательские данные через RLS.

## Как описать AI-модуль

AI Coach следует описывать как вспомогательный модуль принятия решений. Он анализирует ограниченный контекст пользователя и помогает:

- формулировать цели;
- разбивать цели на задачи;
- предлагать привычки;
- анализировать прогресс;
- выбирать следующий шаг.

В дипломе важно подчеркнуть безопасность: API-ключи не находятся на клиенте, запросы проходят через backend, персональные данные минимизируются.

## Как описать геймификацию

Геймификация в Lifera строится вокруг XP, уровней, streak и достижений. Каждое полезное действие создает XP-событие, а достижения фиксируют milestones. Это повышает вовлеченность и помогает пользователю видеть накопительный прогресс.

Можно отдельно показать связь:

- задача выполнена -> XP -> прогресс цели -> возможное достижение;
- привычка отмечена -> streak -> XP -> достижение за регулярность;
- цель завершена -> крупная XP-награда -> рост уровня.

## Как описать стартап-потенциал

Lifera можно развивать как SaaS-продукт:

- бесплатная версия с базовыми целями, задачами и привычками;
- платная подписка с AI Coach, аналитикой и расширенной историей;
- PWA и iOS-версия;
- интеграции с календарем, health-сервисами и финансовыми сервисами;
- B2C-фокус на self-improvement и productivity.

Для диплома это показывает, что проект имеет не только учебную, но и прикладную продуктовую ценность.
