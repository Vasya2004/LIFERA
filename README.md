# LifeOS

LifeOS - персональная цифровая экосистема для управления жизнью, целями, задачами, привычками, навыками, здоровьем, капиталом, достижениями и прогрессом. Продукт проектируется как production-oriented SaaS-приложение с элементами геймификации и AI-помощником, а не как учебная демонстрация.

## Зачем нужен проект

Многие пользователи ведут цели, задачи, привычки, финансы, здоровье и обучение в разных инструментах. Из-за этого теряется общая картина: непонятно, какие действия реально двигают человека к долгосрочным целям, где есть прогресс, а где возникает застой.

LifeOS объединяет эти данные в единую систему:

- показывает состояние ключевых сфер жизни;
- помогает превращать большие цели в конкретные задачи и привычки;
- фиксирует прогресс через XP, уровни, streak и достижения;
- использует AI Coach для рекомендаций и декомпозиции целей;
- готовит основу для будущей PWA и iOS-версии.

## Планируемые модули

- Dashboard - обзор состояния жизни, прогресса, задач и рекомендаций.
- Goals - постановка и отслеживание целей.
- Tasks - ежедневные и проектные задачи.
- Habits - привычки, streak и регулярность.
- Skills - навыки и прогресс развития.
- Health - базовые логи здоровья и самочувствия.
- Capital - учет капитала, доходов, расходов и активов.
- Achievements - достижения, уровни и игровые события.
- AI Coach - персональный помощник для целей, задач и рекомендаций.
- Profile - данные пользователя и персонализация.
- Settings - настройки приложения, приватности и уведомлений.

## Технологический стек

- Frontend: Next.js, React, TypeScript.
- Styling: Tailwind CSS.
- UI: shadcn/ui.
- Backend: Next.js Route Handlers и Server Actions.
- Database: Supabase PostgreSQL.
- Auth: Supabase Auth.
- Access control: Supabase Row Level Security.
- AI: OpenAI API через backend-слой.
- Deploy: Vercel.
- Analytics: PostHog или Vercel Analytics.
- Payments: Stripe в будущих версиях.
- Mobile-first: адаптивное веб-приложение с перспективой PWA и iOS.

## Связь с дипломом

LifeOS может использоваться как объект разработки в ВКР: веб-приложение для персонального управления целями и развитием с AI-рекомендациями и геймификацией. В дипломе можно раскрыть архитектуру SaaS-приложения, модель данных, сценарии пользователей, AI-модуль, механику мотивации и практическую значимость продукта.

## Следующие этапы

На первом этапе зафиксирована документационная и архитектурная основа. Далее проект должен двигаться поэтапно:

1. Инициализация Next.js-проекта только после подтверждения архитектуры.
2. Настройка TypeScript, Tailwind CSS и shadcn/ui.
3. Создание базового layout и дизайн-системы.
4. Подключение Supabase Auth и защищенных пользовательских данных.
5. Реализация onboarding, dashboard и основных модулей.
6. Добавление XP, достижений и AI Coach.
7. Подготовка деплоя, аналитики, тестирования и материалов для диплома.

Первая рабочая версия должна быть сфокусирована на ядре: Auth, onboarding, Dashboard, Goals, Tasks, Habits, XP, базовые Achievements и ограниченный AI Coach. Skills, Health, Capital, Stripe, PWA, сложная аналитика и iOS рассматриваются как последующие этапы, чтобы не перегружать стартовую реализацию.

Подробные правила, спецификации и дорожная карта находятся в папке `docs/`.
